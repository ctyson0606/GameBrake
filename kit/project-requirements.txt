# What a project must hold for the kit to work, one requirement per line:
#
#     path|text|hint
#
# path   a file, relative to the project root. It must exist.
# text   optional. A fixed string (not a pattern) the file must contain. Leave
#        it empty, as in "path||hint", to require only that the file exists.
# hint   what to add and where to copy it from. "upstream" is SparkForge's
#        template/ directory; its files sit at the same paths as here.
#
# Three fields, split on "|", so neither the path nor the text may contain a
# pipe. Blank lines and lines starting with # are ignored.
#
# This is the one list. scripts/check.sh fails each requirement the project
# does not meet, and scripts/update-kit.sh compares the list it replaced with
# the new one and names the requirements that are new and unmet, because it is
# the only place both lists are in hand. Everything here is required: a file a
# project may delete to opt out of a tool belongs in entry-points.txt instead.
